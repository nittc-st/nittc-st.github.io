## Gitとは

Gitは分散型バージョン管理システムです。

## 変更を記録する

作業内容を確認してから、必要なファイルをコミットします。

```sh
git status
git add content/blog/git-basic.md
git commit -m "Gitの基本操作を追加"
git push
```

投稿方法は[READMEの投稿ガイド](https://github.com/nittc-st/nittc-st.github.io#markdownコンテンツの投稿)を参照してください。
