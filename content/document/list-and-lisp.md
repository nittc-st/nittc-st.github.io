## Lispについて

Lisp (List processor) は、プログラミング言語の一つであり、
連続するデータや、記号化に適する言語である。

Lispは、データとプログラムのどちらもリストで表す、
ホモイコニック形式の言語である。

Lispは、その高い表現力から神の言語と呼ばれ、
この世で唯一美しい言語である。

なお、Lispはその圧倒的な美しさから、信仰が存在する。
（ちょっと危ないので、Lisp教には安易に触れないでおこう。）

## リスト

まずは大前提となるリストについて学習する。

Lispは、リストをうまく扱うことですべての処理を実現する。
リストを正しく理解することで、Lispの7割を理解したといえるだろう。

リストは、car部、cdr部によって構成される。
それぞれの部は、リストまたはAtomを持つ。

厳密な定義ではないが、ここではAtomをシンボルや数値等のリテラルとして定義する。

```
       car部            cdr部
| AtomまたはList | AtomまたはList |
```

また、car部、cdr部に要素をもたないリストを、nilとし、
nilを、リストの終端を表す記号として用いる。

```
| | | => nil
```

例えば、`car部:cdr部` と表すとき、以下のリストを考えよう。
- 1 : (2 : (3 : nil))

これを、以下の図で表すこととする。

```
| 1 | o-|---->| 2 | o-|---->| 3 | o-|----> nil
```

続いて、以下のリストを考えよう。
- ((nil : 3) : 2) : 1

これを、以下の図で表すこととする。

```
| o | 1 |
  |
  v
| o | 2 |
  |
  v
| o | 3 |
  |
  v
 nil
```

リストの例
- 1 : (((5 : nil) : 4) : (3 : nil))

```
| 1 | o-|---->| o | o-|---->| 3 | o-|----> nil
                |
                v
              | o | 4 |
                |
                v
              | 5 | o-|----> nil
```

### リストの基本操作

あるリストLを、次のように定義する。
- a : (b : (c : ...))

ただし、a, b, c, ...はアトムである。

```
| a | o-|---->| b | o-|---->| c | o-|----> ...
```

あるリストLについて、car部を取り出す演算をcarと定義し、以下のように記述する。

```
car[L]
= car[ | a | o-|---->| b | o-|---->| c | o-|----> ... ]
= a
```

あるリストLについて、cdr部を取り出す演算をcdrと定義し、以下のように記述する。

```
cdr[L]
= car[ | a | o-|---->| b | o-|---->| c | o-|----> ... ]
= | b | o-|---->| c | o-|----> ...
```

あるアトムまたはリストα及びアトムまたはリストβについて、α:Lを生成する演算をconsと定義し、以下のように記述する。

```
cons[α;L]
= cons[ α ; | a | o-|---->| b | o-|---->| c | o-|----> ... ]
= | α | o-|---->| a | o-|---->| b | o-|---->| c | o-|----> ...
```

これより、リストLは以下のように定義できる。

```
L = cons[ a ; cons[ b ; cons[ c ; ... ] ] ]
```

ここで、cons演算を.を用いて、以下のように表現することとする。

```
cons[α;L]
= (a . L)
```

すると、リストLは以下のように表すことができる。

```
L = (a . (b . (c . ...)))
```

これをS式という。
なお、cons演算はリストにも適用することができる。

### リストの合成操作

続いて、上の基本操作を合成した操作を考える。

あるリストLを、次のように定義する。

```
L = (A . (B . (C . ...)))
  = ((a1 . (a2 . (... . (an . nil))))
     . ((b1 . (b2 . (... . (bn . nil))))
        . ((c1 . (c2 . (... . (cn . nil))) 
           . ...))))

φ = (α . (b . (c . ...)))
```

つまり、

```
| o | o-|---->| o | o-|---->| o | o-|----> ...
  |             |             |
  |             |             v
  |             |           |c1 | o-|---->|c2 | o-|---->|...| o-|---->|cn | o-|----> nil
  |             v 
  |           |b1 | o-|---->|b2 | o-|---->|...| o-|---->|bn | o-|----> nil
  v
|a1 | o-|---->|a2 | o-|---->|...| o-|---->|an | o-|----> nil
```

ただし、A, B, C, a1, a2, ..., bn, ...はリスト、a, b, cはアトムである。

まず、

```
car[L] = A
```

である。続いて、

```
car[car[L]]
= car[A]
= a1
```

である。このように、car演算を複数回行う演算を`ca^nr`と定義する。

```
ca^nr[L]
= car(1)[car(2)[car(...)[car(n)[L]]]]
```

たとえば、

```
caar[L]
= car[car[L]]
```

なお、この演算をcanrと表すこともある。

```
canr[L]
= car(1)[car(2)[car(...)[car(n)[L]]]]
```

つまり、

```
ca2r[L]
= car[car[L]]
```

同様に、

```
cdr[L] = (B . (C . ...))
```

また、

```
cdr[cdr[L]]
= cdr[(B . (c . ...))]
= (C . ...)
```

である。このように、cdr演算を複数回行う演算を`cd^nr`と定義する。

```
cd^nr[L]
= cdr(1)[cdr(2)[cdr(...)[cdr(n)[L]]]]
```

たとえば、

```
cddr[L]
= cdr[cdr[L]]
```

なお、この演算をcdnrと表すこともある。

```
cdnr[L]
= cdr(1)[cdr(2)[cdr(...)[cdr(n)[L]]]]
```

つまり、

```
cd2r[L]
= cdr[cdr[L]]
```

また、これらを順に適用する演算を `c[a|d]+r` (正規表現) と定義する。

たとえば、

```
caaddr[L]
= car[car[cdr[cdr[L]]]]
= car[car[(C . ...)]]
= car[(c1 . (c2 . ...))]
= c1
```

である。

### リストの省略表記

cons演算 `.` について、cdr部にリストを結合する場合のみ、`.`及びcdr部の`()`を省略してよいものとする。
また、nilを結合する場合のみ、cdr部を省略してよいものとする。

たとえば、

```
(a . (b . (c . nil)))
```

であれば、

```
(a b c)
```

となる。

つまり、上で示したリストLは、

```
L = (A B C ...)
  = ((a1 a2 a3 ...) (b1 b2 b3 ...) (c1 c2 c3 ...))
```

となる。
この資料では、この操作を `簡単にする` と呼ぶ。

### 樹形図表現

さて、上で示したリストの図表現であるが、一般には樹形図を用いたほうが便利である。

ノード(car部, cdr部の組み合わせ)を`o`とし、car部、cdr部への連結を`/`や`\`で表す。
また、nilをグランド記号で表す。（ここではnilと記述する。）

リスト `(a b c)` だと、

```
    o
   / \
  a   o
     / \
    b   o
       / \
      c  nil
```

となる。

### 演習

1. リスト `(a . (b . ((c . d) . (e . nil))))`について、以下の問に答えよ。

(1) 樹形図で表せ。

(2) 合成操作により`d`を取り出せ。

(3) このリストを可能な限り簡単にせよ。

2. リスト `(defun square (x) (* x x))` について、以下の問に答えよ。

(1) 樹形図で表せ。

(2) 合成操作により、`defun`, `(* x x)` を取り出せ。

(3) このリストを `.` で表せ。
